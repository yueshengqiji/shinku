# 开发者预览版：已知限制与排错

截至 2026-11-01。本页描述公共源码的边界，不代表维护者某台机器已经加载全部修改。

| 现象/限制 | 含义与处理 |
| --- | --- |
| Agent 未连接 | 未提供可信 ServiceHost 工厂；默认启动不会偷偷继承私人模型/工具。见使用指南 |
| 原生工具不可用、模型灰色或请求被拒 | 模型名称可列出不等于路由支持该工具协议；核对供应商返回、工具能力配置及当前会话状态 |
| 模型超时、余额不足、反代失败 | 先处理实际供应商错误；不能靠换会话或反复继续消除，不应自动无限重试 |
| 上下文未知、命中率未提供 | 当前路由未提供或无法核实容量/用量；不能显示猜测值，累计指标也不是任务成功率 |
| 任务继续被拒 | 权限、尝试、版本、文件或资料可能已变化；先核对状态与已经发生的副作用，避免重放 |
| 文件路径打不开 | 核对当前工作区与实际路径；符号链接、越界、二进制、超限或歧义可能被拒；不要通过扩大权限解决拼写错误 |
| 系统文件选择器不可用 | 当前依赖 Linux 图形会话和 Zenity；服务所在电脑弹窗，其他环境使用手动路径 |
| 日志标记不完整 | 材料原件可能已经截断；分页、搜索、导出不能恢复采集时未保存的内容 |
| 旧产物无法下载 | 路径对应文件已变更/不存在，或回执不能验证；不应把当前同名文件冒充旧产物 |
| 新页面有控件但后端不支持 | 前后端版本不匹配；静态更新不能代替 Python 后端更新 |

## 尚未完成的能力

- **完整 Shell 原始日志链路**：公共日志面板主要读取材料库回执。实验性私用执行器的
  新落盘读取未接通公共工作台；记录格式还发现长行/无换行的还原缺陷。不要承诺所有
  工具日志逐字完整；历史丢失内容不可恢复。本次发布不包含该私用实现。
- **工具覆盖**：公共框架不捆绑任意 Shell、桌面/浏览器控制或私人外发工具。
  用户手工在工作台编辑文件与 Agent 可调用的工具集不是同一授权入口。
- **Goozma 效果**：有候选和评估机制，不等于已证明泛化增益；实验开关不得自动修改业务权限。
- **平台和规模**：不能以 Linux 小规模本地使用推定 Windows/macOS、并发多用户或长期无人值守可用。
- **记忆语义**：引用、召回和来源核验不能保证模型最终理解正确；应保留更正、遗忘与人工复核。
- **独立安装**：核心和前端可单独打包；真实任务仍需要使用者实现工厂并提供模型/工具。
  部分维护脚本依赖本机私用扩展/历史资料，不属于公共快速开始命令。

## 测试证据怎样理解

离线替身测试验证代码行为，不证明真实模型理解、费用、消息送达或工具副作用正确。
历史计划里的测试数量只属于当时版本；发布审计通过不等于全部功能测试通过。
本次发布验证范围见 [发布审计](RELEASE_AUDIT.md)。公共测试不依赖私人数据库与密钥；
需要真实模型、网络或 QQ 的测试必须显式配置，不能在普通试用时盲目运行整库脚本。

最小重现步骤、预期与实际行为。若是恢复问题，说明是否已有文件修改或外部发送。
