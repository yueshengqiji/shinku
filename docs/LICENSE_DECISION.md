# D2：最终许可证决策门槛

项目所有者已选择 Apache-2.0。D2 的代码审计和清洁发布检查、D3 的许可证落地均已完成，
下一步只需进行最终依赖锁定和干净发布包复验。

## 选择项

| 选择 | 结果 | 适合情况 |
| --- | --- | --- |
| 继续私有 / Proprietary | 不公开授权源码；保留现有占位声明 | 只在个人设备或私有环境运行 |
| Apache-2.0 | **已选择**；允许再分发、修改和商用，并提供专利授权和 NOTICE 义务 | 希望建立开放生态，同时保留明确来源和专利保护 |
| MIT | 条款更短、更宽松，保留版权和许可声明 | 希望尽量降低使用者的合规负担 |

第三方依赖的许可证不会因为 Shinku 选择哪一种而消失；它们仍按
`docs/THIRD_PARTY_LICENSES.md` 和各依赖的许可证文本分别保留。

Apache-2.0 的标准文本放在仓库根目录 `LICENSE`；第三方依赖的许可证和 NOTICE 义务
仍然分别保留，不会被 Shinku 的项目许可证覆盖。
