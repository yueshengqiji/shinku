# MCP 与外部能力发布范围

本仓库发布的是能力边界、工具 schema 和授权框架，不是一个默认拥有本机控制权的 MCP 集合。

## 本次版本包含

- 能力清单结构校验与安全拒绝逻辑；
- 工具 schema、风险等级和人工授权边界；
- QQ/NapCat 图片输入与视觉引用桥接；
- 可由使用者自行接入的外部能力接口。

图片桥接只负责把用户明确提供的图片整理成模型输入，不包含用户本机图片目录、Cookie、浏览器会话或第三方账号凭据。

## 本次版本不包含

- 本地 CLI、Shell、PowerShell 或任意命令执行 MCP；
- 文件写入、删除、移动或批量修改 MCP；
- 浏览器自动控制、Cookie 注入或内网访问 MCP；
- API key、Cookie、聊天记录、记忆数据库或用户日志；
- 特定角色的人设、语料、游戏台词、声音或美术素材。

代码中的 `command_exec`、`browser_action` 等字段只是风险模型中的声明类型，不代表随附执行器。高风险能力必须由独立宿主提供，并经过风险策略和明确授权；默认不会自动执行。

## 外部能力接入建议

1. 只提交 manifest/schema，不提交密钥、Cookie 或本机绝对路径；
2. 明确声明能力的风险、作用范围和确认策略；
3. 将图片/只读能力与写入、命令、浏览器控制能力分开；
4. 高风险能力使用隔离进程和最小权限账户；
5. 真实执行前先支持 dry-run，并保留可审计的授权记录。
