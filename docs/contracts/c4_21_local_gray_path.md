# C4-21：QQ 入站到 Agent dry-run 的本地灰测路径

## 目标

验证 C4-18～C4-20 的组合不是“对象可以互相构造”而已，而是能把一条 QQ 入站事件
经过路由、短窗口合并、图片视觉桥、Agent/LLM 桥接，最终得到一条统一出站结果。

## 契约

- 同一会话短窗口内的两条已寻址消息合并为一个 `QQTurn`；
- 图片保持为 `user_images`，不能退化成只有 `[图片]` 的文字；
- Agent 得到一个统一最终文本；
- 未注入 sender 时结果必须是 `dry_run`，不得调用真实 QQ；
- 本批只使用离线 fake runtime，不监听端口、不读取密钥、不重启 NapCat。

## 验收

测试覆盖两条消息合并、图片输入保留、transcript 顺序和 dry-run 出站状态。
