# C4-2：确定性回复路由

## 目的

消息进入模型前先解决“是不是在叫真红”这个问题。模型不应靠阅读整群上下文猜测
自己是否被点名；这既浪费 token，也会制造误回复、复读和追问。

## 默认决策

优先级从高到低：

1. 私聊消息；
2. @ 配置的机器人 ID；
3. 文本开头直接称呼“真红／二阶堂真红／Nikaidou Shinku”；
4. 明确回复机器人的消息；
5. 其他群消息不进入 Agent；
6. 未点名的纯图片默认不进入 Agent。

路由只返回 `RouteDecision`，不调用模型、不发送消息、不执行工具。主动回复概率和
群聊注意力属于后续策略层，不能混进入口确定性判断。

## 灰度口径

本批使用已归一化的 `IncomingMessage` 做纯 Python 决策测试，没有连接 QQ、NapCat、
模型或数据库。它验证的是入口筛选边界，不代表实际账号已经上线。
