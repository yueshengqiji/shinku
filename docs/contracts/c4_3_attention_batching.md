# C4-3：注意力门与短窗口合并

## 目的

群里每条新消息都让模型判断一次，会消耗 token，也会让真红把不属于自己的话题
误接进来。C4-3 把入口注意力拆成无模型的确定性策略，并在进入 Agent 前合并
同一会话的短时间连续请求。

## 契约

- 已被 C4-2 路由确认的消息立即调度；
- 普通群消息只有在主动回复开关打开且随机值命中概率时才调度；
- 默认主动回复关闭、概率为 0；
- 同一会话、同一合并窗口内的已调度消息进入一个 `AttentionBatch`；
- 主消息按优先级选择，直接 @/直呼优先于主动回复；
- 不同会话或超出窗口会先关闭旧批次，不混淆上下文。

概率源和时间都可注入，因此测试不依赖真实随机数和系统时钟。该层不调用 LLM，
也不决定具体人设或工具。

## 灰度口径

本批只测试路由决定、主动回复开关/概率和短窗口合并，没有连接 QQ、NapCat 或模型。
它证明的是“哪些消息值得进入 Agent”以及“几条消息是否合并”的边界。
