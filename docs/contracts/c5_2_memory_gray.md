# C5-2：独立记忆链路灰度

## 目标

验证迁入后的独立记忆层已经接入 QQ Agent 桥接，而不是只把记录写进 SQLite。

## 灰度边界

- 使用临时 SQLite 做写入、回忆、遗忘和作用域隔离测试；
- 使用迁移后的只读灰度库检查普通聊天与明确回忆路径；
- 不发送真实 QQ 消息，不修改旧项目 `9998`，不重载 NapCat；
- 记忆内容只作为带来源的侧块进入 Agent user prompt，不改写主人设。

## 验收项

1. 普通聊天不触发检索，也不把长期事实注入 prompt；
2. 明确回忆可以按当前会话作用域检索；
3. 检索结果带有 `layer` 和 `source_id`；
4. 明确遗忘后记录不再出现在后续检索；
5. 另一群组或私聊作用域不能读取当前会话的记录。

## 结果

- 独立桥接灰测：`1 passed / 0 failed`；
- 配置、记忆和灰测组合回归：`9 passed / 0 failed`；
- `compileall` 和 `git diff --check` 通过；
- 独立后端 `127.0.0.1:19998/health` 返回 `status=ok`；
- 真实 NapCat 出站仍保持关闭。
