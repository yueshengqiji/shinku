# Angelos 独立工作台

Angelos 提供工作区、会话、真实 Agent 任务和文件产物入口。界面资源在
`frontend/angelos/`，单文件原型只作设计参考；正式页面不包含模拟任务。

## 人设与称呼

`src/shinku/angelos/persona.py` 集中维护 Angelos 的正向人设：称呼用户为“主管”，
极度理性、克制，以工作推进和可靠交付为先；在已有授权内主动处理常规步骤，
保留自己的判断，表达直接自然。身份以自身名字和职责建立，不依赖与其他人格比较。
`AngelosRuntime` 为独立宿主注入人设；旧 Bridge 准备器直接答复时也使用同一文本，
已包装的运行时不重复注入。Bot 人格不引用此模块，原有记忆与会话隔离不变。
工作优先不扩大授权，不允许人格表达覆盖宿主回执、任务状态或验收结果。
页面称呼同步为“主管”；历史答复保留原文，源码修改须加载后才影响新请求。

## 编程视图与代码提问

顶部“对话 / 编程”可随时切换；这是浏览器布局，不改变 Agent 模型、权限或任务。
当前页保留代码草稿、选区和对话输入；新建会话也沿用当前视图。刷新页面只恢复视图
偏好，不自动恢复未保存的文件编辑，离开页面时仍有未保存提示。
可输入工作区内的相对路径、绝对路径或从文件改动列表选择文件；只读/编辑、行号、语法高亮及差异
继续由 CodeMirror 提供。选择代码后点击“询问选中代码”，在输入框写问题并发送；
运行中的会话可使用“在新会话提问”，旧任务继续执行。
路径输入支持带成对引号的复制路径、中文/空格和 `./` 前缀；前端按完整目录段
将绝对路径转换为相对路径，后端仍按原边界拒绝符号链接与越界访问。工作区外
路径提示通过旁边的“工作区”按钮选择或创建对应目录，不自动切换或扩大范围。
选区以 UTF-8 JSON 文本附件保存，包含文件、工作区、读取版本、1起始行列及原文；
结束行列为不包含的边界，列按编辑器 UTF-16 位置计数。未保存草稿、读取快照和对照
版本分别标注；不把资料当成最新磁盘事实。单份连同说明最多 12,000 字，每轮最多
8份附件。跨工作区选区拒绝加入；异步上传结果仍归属点击时的会话。

## 运行

安装包和源码均提供 `python -m shinku.angelos`。默认只绑定本机地址：

```sh
python -m shinku.angelos --port 8770 --data-root /absolute/local/data
```

未指定宿主时，页面可管理工作区和草稿，明确显示 Agent 未连接。实际执行需要
可信本机工厂，不接受网页传入 Python 路径、模型密钥或账号。四档权限选择由独立宿主控制器校验：

```sh
python -m shinku.angelos --port 8770 --data-root /absolute/local/data --factory local_host:factory
```

工厂返回 `shinku.angelos.host.ServiceHost`，或 yield 该对象的上下文管理器。
它包装已有 `AgentService`，复用执行器、工具、账本、权限、预算和恢复检查；
工厂负责客户端与协调器的关闭。私用工具或凭据是可选本机依赖，不随公共包分发。
独立服务提供 `/angelos`，不挂载控制中枢或 QQ Webhook，也不改变原主后端入口。

## 状态与边界

- `data-root/angelos/workbench.sqlite3` 保存工作区、会话、文本附件及结果展示副本。
  Agent 任务的状态、核验和取消回执以 AgentPort 为准；页面收到回复不等于任务验收通过。
- 输入先落盘，模型准备在有界线程池运行，同一会话只接收一项活动任务。
  模型生成的任务条件须通过原宿主的效果资格和明确目标覆盖检查后才允许提交。
  请求编号重复提交不会重复执行；同编号不同内容拒绝。重启不自动重放未完成的准备。
- 恢复必须显式操作，并携带用户看到的尝试/版本，继续由 Agent 原有权限和恢复规则裁决。
  WAW 在实际副作用工具入口展示绑定本任务、尝试、权限版本和参数的单次批准；拒绝、取消、超时或撤权均不执行。
- 会话上下文与工作区说明随请求传入。目录必须存在，但登记目录本身不扩大工具权限。
  上下文压缩与容量策略由实际宿主处理；未知容量不能猜测，原文与执行记录另行保存。
- 目前上传 UTF-8 文本，每份最多 12,000 字、每轮最多 8 份，总输入另有限额。
  二进制附件明确拒绝。产物只从对应会话的执行回执下载，实际 SHA-256 必须匹配，最大 32 MB。
- 模型选择位于输入框上方，按会话保存供应商模型与思考档位；运行中任务不因其它会话切换而换模型。
- 本机请求校验 Host、Origin 和 Fetch Metadata，写操作还需进程令牌。
  页面不输出密钥，资料仅在明确发送后进入模型请求。此入口面向可信本机用户。

## 验收与回滚

`tests/angelos_fixture.py` 使用真正的 AgentService 和隔离文件工具，但模型是确定性替身。
可以在独立临时目录启动验收服务，覆盖会话、提交、核验和下载而无需付费或 QQ 发送。
工作台数据是新增独立数据库；回滚源码时保留数据库备份，不删除既有 Agent 账本。

## 四档权限和文件面板

宿主用 `ServiceHost(..., permissions=PermissionControls(path))` 显式启用本功能。
`PermissionControls` 自己保存状态，不写 Bot 命令文件。原宿主仍负责身份、候选工具与预算上界。
本机 Linux 工厂在装配前调用 `require_unprivileged()`，拒绝 root 启动并设置可继承的
`no_new_privs`，阻止执行 setuid/文件 capability 获得新权限；不向模型提供 sudo 凭据或 root 会话。
此助手仍拥有当前系统用户本来的文件权限，并非文件系统沙箱。

| 档位 | 行为 |
|---|---|
| ZAYIN | 不向模型提供业务或内部工具；仅对话 |
| HE（黄色） | 仅允许没有写入/命令等效果的只读工具 |
| WAW（紫色） | 只读自动执行，副作用工具在宿主等待一次明确批准 |
| ALEPH（红字加粗） | 宿主已安装并授权的工具无需逐项确认，无 root |

首次配置默认为 HE。切换立即更换权限版本，旧任务在下一检查点失效；
已启动操作不承诺回滚。恢复旧任务仍保留原服务的权限不得扩大检查，需要扩大权限时发送新任务。
批准不能扩大参数、恢复旧版本或越过材料、契约、预算和真实结果验收。

顶部“文件改动”每 2.5 秒读取实际磁盘状态。Git 根目录对照 HEAD（含暂存和未跟踪文件）；
普通目录对照首次观察快照。显示各文件增删行数，不把外部编辑冒充 Agent 改动。
普通目录快照最多 2,000 文件和 16 MiB；单文件 UTF-8 预览/编辑最多 512 KiB。
无法预览的文件明确计入提示。无目录的工作区需先关联目录。

代码面板使用随应用打包的 CodeMirror 6，含行号、函数/类/关键字等语法配色、双栏差异和单栏源码。
这是语法高亮，不声称具有 VS Code 的语言服务、类型诊断或调试器。
WAW/ALEPH 可由用户明确保存编辑，HE/ZAYIN 只查看；保存与 Agent 执行回执分开记录。
保存携带原字节 SHA-256；外部变更时拒绝覆盖，草稿留在编辑器。重新读取/换文件先处理未保存草稿。
路径穿越、链接跳转、硬链接写入、二进制和超限内容拒绝。人工编辑前的原文保存在本机工作台数据库。

编辑器离线资源可复建：在 `frontend/angelos/editor/` 运行 `npm ci --ignore-scripts` 和 `npm run build`。
锁文件与第三方许可证随源码保留，页面不依赖外部 CDN。旧后端未加载新接口时仍可继续原有对话，
新权限和文件能力显示为待加载，不能以静态页面更新冒充后端功能已部署。

### 本机系统路径选择

编程视图的“选择文件…”打开桌面系统文件选择窗口；选中后沿用工作区文件读取、
行号/高亮和未保存草稿确认。新建或编辑工作区时，“浏览目录…”填入本地目录，
仍须点击创建/保存。工作区外文件不会自动扩大权限或更改当前工作区。

本功能通过本机受令牌/同源保护的接口调用 Zenity，需要 Linux 图形会话与 `zenity`。
窗口出现在服务所在电脑桌面；不支持从另一台电脑选取远端磁盘。不可用时仍可
手动输入路径。窗口最多等待150秒，同实例只开一个；取消、连接断开和超时会回收
子进程。等待不持有工作台锁，也不调用模型。选择期间切换工作区、重开表单或手动
改写输入后，旧结果不覆盖新状态。

该功能包含新后端路由，源码更新后仅刷新网页不足以生效；须加载配套后端和前端。
